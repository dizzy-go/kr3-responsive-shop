# Контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Ссылки на проект
- **Репозиторий GitHub:** https://github.com/dizzy-go/kr3-responsive-shop
- **Опубликованный сайт (GitHub Pages):** https://dizzy-go.github.io/kr3-responsive-shop/

## Описание
TechNova — это адаптивная версия многостраничного сайта интернет-магазина современной электроники и гаджетов. Дизайн выполнен в современном минималистичном стиле (вдохновлен UI-китами из Figma).

## Структура
- `index.html`, `catalog.html`, `product.html`, `order.html`, `contacts.html` — страницы;
- `css/style.css`, `css/responsive.css` — стили;
- `js/main.js` — скрипт переключения темы, валидации, фильтрации и модального окна;
- `lighthouse/` — отчёты аудита;
- `images/` — изображения.

## Адаптивные решения
- использован подход Mobile First;
- добавлены медиазапросы для 768px и 1024px;
- адаптирована сетка карточек (1 -> 2 -> 3 колонки);
- адаптирована форма (1 -> 2 колонки);
- использованы responsive images (`srcset`, `sizes`).

## Доступность (A11y)
- добавлена ссылка пропуска к основному содержимому (`skip-link`);
- добавлен и проверен видимый фокус (`:focus-visible`);
- проверены формы, связаны `label` с полями;
- для ошибок формы добавлены `aria-describedby` и `role="alert"`;
- семантическая разметка (один `h1` на страницу, `header`, `nav`, `main`).

## Самостоятельные доработки (для максимальной оценки)
1. **Современный дизайн-код:** внедрена обновленная цветовая палитра, типографика, тени и скругления в стиле современных Figma-шаблонов.
2. **Адаптивное бургер-меню:** для экранов до 768px реализовано выпадающее меню с JS-переключением и `aria-expanded`.
3. **Карточное представление таблицы:** таблица характеристик на мобильных экранах трансформируется в карточки с помощью `data-label` (без горизонтального скролла).
4. **Продвинутые изображения:** на главной странице для главного товара используется тег `<picture>` с поддержкой формата WebP (если браузер не поддерживает, грузится JPG).
5. **Доступное модальное окно:** реализован «Быстрый просмотр» товара с использованием нативного `<dialog>`, который автоматически удерживает фокус внутри окна.
6. **Фильтрация каталога:** реализована динамическая фильтрация по категориям и цене.
